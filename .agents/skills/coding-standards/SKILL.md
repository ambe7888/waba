# Normes de Développement & UI/UX - WhatsClick

Ce skill définit les règles obligatoires pour tous les agents travaillant sur la base de code WhatsClick.

## 1. Conservation et Intégrité du Code
- Interdiction d'altérer ou perturber la logique existante sans demande expresse.
- Les corrections et ajouts doivent être ciblés et rétrocompatibles.

## 2. Thème Graphique & Palette
- Respect strict du thème graphique existant (couleurs vives, cartes blanches, ombres subtiles).
- **Zéro fond gris générique** (`#eee`, `#ccc`, `bg-gray`, etc.).

## 3. Typographie & Composants UI
- Pas d'icônes intégrées au milieu des paragraphes ou textes explicatifs.
- Boutons avec des textes courts et compacts.
